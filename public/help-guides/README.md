# Help guide screenshots

One folder per guide, one file per step, named by the step number counted
across the whole guide:

    public/help-guides/<guide slug>/step-1.png
    public/help-guides/<guide slug>/step-2.png

The guide slug is the last part of the guide address, for example
`browsing` for /help/browsing. A missing file is hidden on the page, so a
guide works before all its screenshots exist.

A screenshot uploaded in Storefront, Help Guides replaces the file for that
step. `browsing/step-1.png` is a sample placeholder.
